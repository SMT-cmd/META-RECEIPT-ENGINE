    What remains safe?

    • Your old password and Firebase sign-in stay in place.
    • Existing short receipt links keep working; no link is redirected.
    • You can download a JSON archive before changing anything.
    • Cloud records are read only; nothing is removed or rewritten.
    • Importing twice will not duplicate the same records.

    What about my future subdomain?

    The new platform is being prepared for individual business addresses such as myshop.platform.com. This wizard does not create a live subdomain yet, and it does not transfer login sessions between unrelated domains.

    For accounts opened from a different website, use the downloaded backup when the hosted migration importer is available. Keep the backup private: it can contain customer and transaction information.
